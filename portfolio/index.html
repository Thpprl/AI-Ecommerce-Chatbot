PADDLEOCR vs QWEN-VL

Two approaches. The same evaluation images.

I compared PaddleOCR with Qwen-VL on the same image set, and fine-tuned Qwen-VL using LoRA / PEFT as part of my model development work.

PaddleOCR

OCR approach for reading text from license plate crops.

Qwen-VL

Vision-language approach for extracting plate information, with hands-on model fine-tuning.

The shared image set provides a common basis for comparison. Separate per-model scores are not presented here; the report results below do not establish which model performs better.

Plate color: 98% · Text color: 90%. Source: Technical Report, section 4.1. These are reported system results, not separate PaddleOCR and Qwen-VL scores. Results apply to this evaluation set.

Read project overview +

Problem: Turn license plate images into readable text.

Pipeline: YOLOv8s detection → region-of-interest crop → OCR / Qwen vision-language recognition → normalization → color-based vehicle classification.

Data preparation: The technical report describes 11,343 annotated images: 9,074 training, 1,134 validation, and 1,135 test images. These splits are distinct from the 50-image reported evaluation.

Automated annotation: Used the Gemini API to label 10,000+ license plate images automatically, producing model-generated annotations to help cross-check the outputs of my LPR system.

Engineering decisions: Crop the plate to reduce background noise. Normalize province names, colors, and vehicle labels before field-level scoring. Evaluate both character-level errors and exact field matches.

Limitations: Blur, glare, small characters, camera angle, and imperfect crops can propagate errors through the pipeline. Low character error does not imply a fully correct plate string.
